Every design installs with the official shadcn CLI under the `@iloveui` namespace. The CLI writes the component into your project, installs its dependencies with your package manager and adds the tokens if they are missing. You need a `components.json`; `npx shadcn@latest init` creates one.

## Set up

Register the namespace once. This command adds it to your `components.json`:

```bash
npx shadcn@latest registry add @iloveui=%SITE_URL%/r/{name}.json
```

It writes this entry, which you can also add by hand:

```json title="components.json"
{
  "registries": {
    "@iloveui": "%SITE_URL%/r/{name}.json"
  }
}
```

Then install any design by its slug, the last part of its URL:

```bash
npx shadcn@latest add @iloveui/gridline-hero
```

That one command:

- writes `components/iloveui/gridline-hero.tsx` (the folder follows the `components` alias in `components.json`);
- installs the design's dependencies, here `motion` and `lucide-react`;
- installs `@iloveui/tokens`, adding any `--iu-*` variable your stylesheet does not have yet and keeping the ones it has.

## When something fails

Registry items are static JSON files, so the only error you are likely to see is a 404: no design has that slug. Copy the slug from the design page's install bar, or list every design with the search command below.

## More commands

See what a design would write before installing it:

```bash
npx shadcn@latest view @iloveui/gridline-hero
```

Install several designs at once:

```bash
npx shadcn@latest add @iloveui/gridline-hero @iloveui/margin-notes-testimonials
```

Search the catalog from your terminal:

```bash
npx shadcn@latest search @iloveui --query pricing
```

Reset every token to the defaults (the CLI asks before it overwrites your values):

```bash
npx shadcn@latest add @iloveui/tokens
```
