iloveui is a catalog of hand-built UI designs: complete hero sections, pricing tables, dashboards, forms, agent consoles and more, each one ready to paste into a real app. Every design comes in two formats, re-themes to your brand, and lists exactly what it costs your bundle.

## What a design is

A design is one self-contained piece of product UI, built in one of eight style families and designed for light and dark, from 375 to 1440 pixels wide. It ships as:

- **React + Tailwind v4**: a single `component.tsx` with typed props and defaults. Paste it into any Next.js or Vite app.
- **HTML + Tailwind v4**: a `component.html` with the same markup and vanilla JavaScript for the interactive parts. No framework.

Both read the same ten `--iu-*` CSS variables, so one set of tokens themes every design you use. The only runtime dependencies a design can have are `react`, `motion` and `lucide-react`.

Each design page shows its receipts in a row of mono labels: the gzipped size of the component, its runtime dependencies (or "0 deps"), the axe accessibility result and whether it supports reduced motion.

## How the pieces fit

1. **Browse.** [Designs](/designs) filters by category, style family, motion and format, and keeps the filters in the URL. Press <Kbd>⌘</Kbd> <Kbd>K</Kbd> (or <Kbd>Ctrl</Kbd> <Kbd>K</Kbd>) to search from anywhere.
2. **Preview.** The stage on each design page renders the live component. Switch between 375, 768 and 1440 pixels or Full, drag the handle to any width, flip light and dark, step through its states and press Replay to watch its motion again.
3. **Theme.** Theme Lab sits at the bottom of the browse and design pages. Pick an accent, a neutral, a radius, a font and a density, and every preview changes with you. See [Theming](/docs/theming).
4. **Take the code.** Copy a file from the React or HTML tab, install with the shadcn CLI, download a zip, or copy the AI prompt for your coding agent. Copies and downloads carry your Theme Lab tokens.
